# Sticky ToDo 仕様書（完成版）

更新日：2026-09-13  
対象：Sticky ToDo Windows版 1.0.0

## 1. 目的とコンセプト

制作・業務タスクを付箋紙としてボードに貼り、カテゴリ、期限、優先度を一目で確認できる個人向けToDoアプリ。期限が近い付箋紙ほど赤く表示し、緊急度を視覚化する。

## 2. 技術構成

- フロントエンド：React 19 + TypeScript
- ビルドツール：Vite
- アイコン：Lucide React
- デスクトップアプリ化：Tauri 2
- バックエンド：Rust
- データベース：SQLite（rusqlite、bundled SQLite）
- 保存形式：SQLiteデータベースを格納した `.tdf`（ToDo File）
- ファイル選択：Tauri Dialogプラグイン
- 対応OS：Windows x64
- 暗号化：採用しない。`.tdf` は通常のSQLiteファイルとして扱う

## 3. 保存と永続化

### 3.1 ファイル操作

- 初回起動時に「新しい .tdf を作成」または「既存ファイルを開く」を選択する
- `.tdf` はユーザーが選んだ場所に保存する
- 「セーブ」で現在の全タスク状態を保存する
- 「ロード」で現在開いている `.tdf` を読み直し、保存済み状態を復元する
- 操作後は自動保存される

### 3.2 データ構造

```json
{
  "id": "string",
  "category": "テキスト | イラスト | ゲーム | 動画 | ウェブ | SNS | 受注 | その他 | 追加カテゴリ",
  "title": "string",
  "body": "string",
  "dueDate": "YYYY-MM-DD | null",
  "priority": "至急 | 急 | 並 | やったほうがいい | やれたらやる",
  "createdAt": "timestamp",
  "done": "boolean",
  "doneAt": "timestamp | null",
  "locked": "boolean"
}
```

`doneAt` は完了にした日時、`locked` は完了付箋紙の施錠状態を表す。ボードへ戻した場合は `done=false`、`doneAt=null`、`locked=false` になる。

## 4. 付箋紙

### 4.1 入力項目

| 項目 | 内容 |
|---|---|
| 種類 | 8つの標準カテゴリまたは追加カテゴリから1つ |
| タイトル | ボード・完了タブに表示する短い名前。必須 |
| 内容文章 | 詳細メモ・本文。任意 |
| 期限日 | 日付。未設定可 |
| プライオリティ | 至急／急／並／やったほうがいい／やれたらやる |

### 4.2 表示と並び順

ボードはカテゴリごとの固定レーンを縦方向に表示する。レーン内は次の順に左から並べる。

1. 期限日が設定された付箋紙を期限日昇順
2. 期限日が同じ場合はプライオリティの高い順
3. 期限日未設定の付箋紙は右端

### 4.3 色分け

| 期限まで | 色 |
|---|---|
| 7日以上・期限なし | 黄色 |
| 3〜6日 | オレンジ |
| 1〜2日 | 赤寄り |
| 当日・期限超過 | 濃い赤 |

## 5. 基本操作

- 左クリック：付箋紙を選択し、画面下部の詳細エリアにタイトル、本文、カテゴリ、期限日、プライオリティを表示する
- 右クリック：コンテキストメニューを表示する
- 未完了付箋紙のメニュー：編集／完了／削除
- 完了付箋紙のメニュー：ボードに戻す／編集／削除
- 編集：既存内容を変更する。完了履歴や鍵状態は維持する
- 削除：確認後に対象付箋紙を削除する

## 6. 完了タブ

### 6.1 完了への移動

未完了付箋紙で「完了」を選ぶと、ボードから完了タブへ移動する。元のカテゴリ、本文、期限日、プライオリティは保持し、`doneAt` に完了日時を記録する。

### 6.2 完了タブの表示

完了付箋紙は完了日時の新しい順に表示し、完了日時が同じ場合は登録日時の新しい順にする。一覧には次を表示する。

- タイトル
- 鍵状態
- カテゴリ
- 期限日
- プライオリティ
- 完了日

完了付箋紙をクリックすると、下部の詳細エリアで本文を確認できる。

### 6.3 施錠

完了付箋紙の施錠アイコンを押すと、鍵のON／OFFを切り替える。鍵付きの完了付箋紙は「完了を削除（鍵なし）」の対象外になる。

### 6.4 ボードに戻す

完了付箋紙を右クリックし、「ボードに戻す」を選択すると、鍵の有無に関係なくボードへ戻す。カテゴリ、期限日、プライオリティ、本文は維持し、完了状態・完了日時・鍵だけを解除する。

### 6.5 完了を削除

「完了を削除（鍵なし）」を実行すると、鍵の付いていない完了付箋紙を一括削除する。鍵付きの完了付箋紙は残す。

## 7. カテゴリ管理

### 7.1 標準カテゴリ

テキスト、イラスト、ゲーム、動画、ウェブ、SNS、受注、その他を標準カテゴリとして常時表示する。

### 7.2 追加・変更

- ボード最下部の「カテゴリを追加」でカテゴリを追加する
- カテゴリ名を右クリックし、「カテゴリ名の変更」で改名する
- 改名時は、そのカテゴリに所属する付箋紙のカテゴリも同時に変更する
- 付箋紙が多いレーンはレーン内を横スクロールする
- カテゴリが増えた場合はボード全体を縦スクロールする

### 7.3 削除

カテゴリ名を右クリックし、「削除」を選択する。

- 付箋紙がない場合はカテゴリを削除する
- 未完了・完了を含め付箋紙が残っている場合は、ネイティブ確認ダイアログで「はい／いいえ」を表示する
- 「いいえ」なら何も削除しない
- 「はい」ならカテゴリと所属する全付箋紙を削除する
- 鍵付きの完了付箋紙が1つでもある場合は、警告「鍵付きの完了付箋紙があります。カテゴリを削除できません。」を表示し、確認ダイアログを出さず削除しない

## 8. 画面構成

- ヘッダー：現在の `.tdf` 名、セーブ、ロード、開く、新規付箋紙
- タブ：ボード、完了タブ。件数バッジ付き
- ボード：カテゴリ別レーンと付箋紙
- 完了タブ：完了履歴と一括削除
- 下部詳細エリア：選択中付箋紙の詳細
- ダイアログ：付箋紙入力、ファイル選択、カテゴリ削除確認

## 9. 非機能要件

- Windows x64で単体実行版とNSISインストーラー版を提供する
- React/TauriのWebView表示により、日本語を含む文字をOSネイティブ描画より安定して表示する
- 個人利用を前提とし、`.tdf` ファイルをユーザーが管理する
- アプリ終了後もタスクデータを保持する
