# 第63課題：AI付箋下書き（ローカルWeb版）

OpenAI Responses APIのStructured Outputsで、入力文からtitle/body/category/dueDate/priorityのJSONを生成します。サーバーで項目・文字数・カテゴリ・優先度・期限日を検査し、利用者が既存の編集画面で確認してから保存キューへ登録します。

## 起動

プロジェクトフォルダでPowerShellを2つ開きます。

```powershell
node ai-server.mjs
```

```powershell
npm run dev
```

http://127.0.0.1:1420/ を開き、「AIで付箋の下書き」から文章を入力します。入力した文章と現在のカテゴリ名だけをOpenAIへ送ります。既存の付箋一覧は送信しません。

AIキーはGitで無視される.env.localのOPENAI_API_KEYからサーバーだけが読みます。VITE_で始まる変数にはキーを入れません。今回作成したキーは24時間で失効します。API利用には利用可能な残高・枠が必要です。

ローカル開発用の機能です。本番ビルドではAIボタンを表示せず、Cloudflareへの公開は未設定です。公開前には利用者認証・サーバー側の利用上限・Secret設定が必要です。デスクトップ版は対象外です。

ローカルサーバーは127.0.0.1に限定し、入力サイズ制限・1件ずつの実行・毎分5回までの受付・タイムアウトを設けています。生成拒否・不完全な出力・不正な日付やカテゴリは保存せずエラーにします。
