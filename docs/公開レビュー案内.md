# Sticky ToDo：課題用ソースレビュー

このブランチは学習成果をレビューしてもらうためのソース公開です。mainへのマージや本番公開は行いません。

## 最初に見る場所

- 画面・付箋の保存：src/App.tsx
- API：functions/api/status.js（固定ステータスのみ、付箋データは返しません）
- ローカルAI下書き：ai-server.mjs、src/AIEntry.tsx
- ローカルRAG：rag.mjs、rag-server.mjs、src/RAGEntry.tsx
- エージェント：agent-demo.mjs
- 監査ログ：audit.mjs、server.mjs
- SLIの手動計測：sli.mjs
- 自動テスト：tests/
- 構成図：docs/アーキテクチャ図.md
- 設計判断：docs/adr/0001-端末内保存を維持する.md

## 再現の範囲

Node.js 24で `npm ci` → `npm test` → `npm run build`。
Web画面は `npm run dev`。AIサーバーは別起動が必要です。
AIの実API呼び出しにはレビュー者自身のOpenAI APIキーと利用料が必要です。キーは公開しません。
自動テストはモックを使用し、実APIキーは不要です。
詳細はAI下書き.md、RAG実験.md、エージェント実験.md、SLOとSLI.mdを参照してください。

## 注意点・レビューしてほしい点

WebはlocalStorage、desktopはSQLite .tdfであり、ログイン・共有DB・端末間同期は未実装です。
AI/RAGのUIはローカル開発用です。loopback制限やOriginチェックは利用者認証ではありません。
引用一致の評価は意味的な正確さ・網羅性を保証しません。
監査ログはローカルNode配信の標準出力のみで、永続保管・改ざん防止は未実装です。
デスクトップのファイル権限、入力の実行時検証、依存関係の更新などにも改善余地があります。
この公開を本番品質・完全な安全性の保証とは扱わないでください。

秘密ファイル、付箋の実データ、埋め込みキャッシュ、実行出力は公開対象外です。
