# Sticky ToDoが節約する時間・お金・手間

## 概要

Sticky ToDoは、付箋紙の感覚でタスクを登録しながら、カテゴリ・期限・優先度・完了状態をまとめて管理できるWindows向けToDoアプリです。

紙の付箋や複数のメモを使い分ける場合に発生しやすい「探す」「並べ替える」「完了済みを整理する」といった作業を減らします。

## 1. 節約できる時間

| 場面 | 節約できる時間の目安 |
| --- | ---: |
| 思いついた用事をメモする | 1件あたり1〜3分 |
| 紙・メモ帳からタスクを探す | 1日5〜10分 |
| 期限や優先度を確認する | 1日3〜5分 |
| 完了済みの作業を整理する | 週10〜20分 |
| 過去の付箋紙を探す | 1回5〜15分 |

毎日10分を削減できると、月20営業日で約3.3時間、年間では約40時間になります。

時間の価値を時給2,000円として換算すると、年間約8万円分の時間を節約できる計算です。

## 2. 節約できるお金

Sticky ToDoは、サーバー利用料や月額のクラウド契約なしで利用できる構成です。

節約効果が考えられる費用は次のとおりです。

- 有料タスク管理サービスの月額料金
- 紙の付箋・ノート・手帳の購入費
- 期限忘れによる再作業・延滞・キャンセル費用
- タスク管理を人に依頼する費用
- 複数のツールを使い分ける費用

例えば、月額1,000円のサービスを使わずに済めば、年間12,000円の直接削減になります。

## 3. 節約できる手間

- 付箋を貼り直す
- 終わった付箋を捨てる
- 未完了と完了を分ける
- 期限順・重要度順に並べ替える
- カテゴリごとに作業を分類する
- 完了した仕事の内容を後から確認する
- 鍵付きの完了付箋紙を管理する
- `.tdf`ファイルとして保存・再開する

完了したタスクも元データを保持したまま確認できるため、「以前何をしたか」を探し直す手間も減ります。

## 4. 「もし人に頼んだらいくら？」の目安

同じ仕様のWindows向けデスクトップアプリを新規開発すると仮定した場合の概算です。

| 依頼先 | 想定費用 |
| --- | ---: |
| 個人開発者・フリーランス | 150万〜350万円 |
| 小規模開発会社 | 250万〜500万円 |
| 大手・受託開発会社 | 400万〜700万円以上 |
| 保守・小改修 | 年20万〜80万円程度 |

国内のシステム開発では、フリーランスから大手まで含めた人月単価が約60万〜200万円とされ、画面数が少ない単機能ツールでも100万〜300万円程度が一つの目安とされています。

### 見積もりに含まれる主な作業

- 要件整理と画面設計
- Reactによる画面開発
- TauriによるWindowsデスクトップ化
- Rust側のファイル保存処理
- `.tdf`ファイルの読み書き
- カテゴリ管理
- 完了タブ
- 期限・優先度表示
- ロック機能
- 右クリックメニュー
- 確認ダイアログ
- Windows用exe・インストーラー作成
- 動作確認・不具合修正
- マニュアル・仕様書・引き継ぎ資料の作成

単純なToDoリストよりも、業務用の小規模デスクトップアプリに近い内容です。

## 5. 利用者1人あたりの費用対効果

利用者が毎日10分を節約できる場合の試算です。

| 項目 | 試算 |
| --- | ---: |
| 月間削減時間 | 約3.3時間 |
| 年間削減時間 | 約40時間 |
| 時間価値を2,000円とした場合 | 約8万円／年 |
| 時間価値を3,000円とした場合 | 約12万円／年 |

5人で使う場合は、年間約40万〜60万円相当の時間削減になります。

## まとめ

Sticky ToDoの価値は、単にタスクを保存することではありません。

毎日の「書く」「探す」「並べる」「確認する」「片付ける」という小さな作業をまとめて減らし、期限忘れや再作業も防ぎます。

個人利用では、毎日の整理時間を減らすアプリとして利用できます。チーム利用では、タスク確認・整理・完了履歴の確認・引き継ぎにかかる時間を減らす業務ツールとして活用できます。

> 金額は機能範囲、品質保証、デザイン、納期、保守契約によって変動する概算です。実際に発注する場合は、要件定義と受け入れ条件を明確にしたうえで複数社から見積もりを取る必要があります。
