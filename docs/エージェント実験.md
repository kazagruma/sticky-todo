# 第65課題：ローカルの資料調査エージェント

## 実行方法

StickyTodoAthenaフォルダのPowerShellで `node agent-demo.mjs` を実行します。
質問を変える場合は `node agent-demo.mjs "Web版のデータ保存先を調べて保存して"`。
OpenAI APIを使用するため少額の料金が発生します。キーは追跡対象外の `.env.local` に保存します。

## 動き

質問 → AIが読む資料を選択 → read_document → 根拠つき要約 → evaluate_and_save → ローカル保存 → 終了。
固定手順を順番に実行するだけではなく、SDKのループでAIがツール・資料・終了を選びます。
許可資料はREADME.md、docs/API.md、docs/AI下書き.mdのみ。新しい任意資料は読みません。

## 評価と実測

2026-10-14の実行でREADME.mdを読み、Web版のデータ保存先を要約・保存しました。
評価は3/3点（回答あり、許可資料、引用の原文一致）。保存先は `.agent-output/` 内のランダムな新規JSONです。
最終応答はアカウント共有が未対応なことにも言及しましたが、保存された主張は保存先のみでした。
したがって、この評価は質問への網羅性や意味的正確さを保証しません。提出前には人が確認します。

## 安全ガード

- 最大6モデルターン、最大6ツール呼び出し、90秒の中断シグナル。
- 入力500文字以下、秘密キーらしい文字列を拒否。
- 3資料の固定リストと原文引用検証。架空の出典・引用を拒否。
- 保存は実験フォルダ内の新規ファイル1件のみ、上書き不可。任意パスを指定するツールはありません。
- シェル・削除・本番更新・付箋データ操作のツールを提供しません。
- トレース送信を無効化。読んだ許可資料と質問はOpenAIへ送信されます。
- 根拠がない時は保存せず終了するよう指示。これは指示だけでなく保存前の検査でも補強します。
