# 第64課題：ローカルRAG

対象はREADME.md、docs/API.md、docs/AI下書き.mdの3件だけ。実際の付箋や他プロジェクトの資料は取り込まない。本番公開は行わない。

## 起動

プロジェクトフォルダでそれぞれ実行する。

```powershell
node rag-server.mjs
npm run dev
```

別々のPowerShellで起動し、http://127.0.0.1:1420/ の「資料に質問する（RAG）」を開く。APIキーは.env.localのOPENAI_API_KEYをサーバーだけが読む。

## 仕組み

初回質問時に3資料を読み、1000文字までの断片に分割し、text-embedding-3-smallで512次元のベクトルに変換する。ベクトルはGit対象外の.rag-cache/index.jsonに保存し、資料・モデル・次元数のハッシュが変わった場合だけ再取り込みする。

質問も同じモデルでベクトル化し、コサイン類似度上位4断片をgpt-4o-miniへ渡す。資料だけに基づく主張・資料ID・引用をJSONで受け取り、資料IDと引用の原文一致を検査する。引用箇所は確認しやすいよう行全体で表示する。

資料に答えがない場合は主張を空にし、根拠がないと返す。原文一致は回答が引用から正しく導けることを保証しないため、人が回答と原文を確認する。README等が古い場合は回答も古くなる。

今回の小規模実験では全ベクトルとの比較で十分。大量資料向けのベクトルDBや継続収集は未実装。受付は毎分5回・同時1件、ローカル接続だけに限定している。
